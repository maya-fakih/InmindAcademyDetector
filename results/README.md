# Results

One subfolder per trained run, each holding `report.md` (eval metrics,
loss/mAP curves, sample ground-truth-vs-prediction images) generated by
`generate_report.py`. Checkpoints stay on Drive, not here -- only the
readable report + small images are committed.

## Generate a report (run after training, e.g. in Colab)

```bash
python results/generate_report.py \
  --run-name malek_rcnn_baseline \
  --weights /content/drive/MyDrive/AcademyObjectDetection/runs/baseline/weights/best.pt \
  --config /content/drive/MyDrive/AcademyObjectDetection/config.yaml \
  --log-file train.log
```

Writes `results/<run-name>/report.md`, `curves.png`, and
`predictions/*.png`. Calls the repo's own `eval.py` / `predict.py`
under the hood -- doesn't reimplement or modify them.
